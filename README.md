# sealed-server

A new Go project created with gostarter.

## Getting Started

This is a web server application built with Go.

### Prerequisites

- Go 1.19 or later

### Installing

```bash
go mod tidy
```

### Running the application

```bash
go run cmd/sealed-server/main.go
```

The server will start on `:8080`.

### API Routes

- `GET /` - Home endpoint
- `GET /health` - Health check endpoint
